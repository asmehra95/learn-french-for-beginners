# Audio credits

The native-speaker recordings in this folder come from [Lingua Libre](https://lingualibre.org/), via [Wikimedia Commons](https://commons.wikimedia.org/). Each file keeps its original license (CC0, CC BY or CC BY-SA). Files under CC BY or CC BY-SA must be credited to the speaker listed below. Files under CC BY-SA may only be shared under the same license.

Changes made: each file here is the MP3 version that Wikimedia Commons generates automatically from the original WAV upload, renamed to a short ASCII file name. The audio content itself was not edited. This applies to the files from the first download (Lessons 1–5). The 698 files added later (every clip for verbs 26–125, plus the new and upgraded clips for verbs 1–25) were also trimmed of leading and trailing silence and loudness-normalised with ffmpeg, except: none.

Coverage (all 125 verbs): infinitives 125 / 125, present-tense forms 626 / 740 (12 say the full phrase with the pronoun), past forms 118 / 125, future forms 0 / 125, example sentences 0 / 125. Items without a recording use the browser's computer voice instead.

"Says" is the exact text spoken in the recording. Sometimes it is only the verb form without the pronoun (for example `suis` for "je suis"). Full-phrase recordings play from the "Native speaker" button; the others from "Native speaker (word only)".
